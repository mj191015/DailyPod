# 2차 알림(스트레칭 미션) 실기기 체크리스트 — BGM + 가이드 화면

통과/실패 칸에 ✅ / ❌ 와 메모를 적어 주세요. 기기: iPhone 15 Pro Max · 날짜: ____________

## 앱 메뉴

| 메뉴 | 용도 |
|---|---|
| **Test E: BGM 재생** | 큰 소리 BGM이 끊김 없이 반복되는지 (A) |
| **Test F: 스트레칭 가이드** | 반투명 목표 머리와 내 머리 비교 화면 (B) |
| **2차 알림 시뮬레이션** | 누르면 BGM 시작 + 가이드 화면이 열림. 가이드의 **완료** 버튼을 누르면 BGM 정지 |

> 시뮬레이션에서 **뒤로 가기**로 나가면 BGM은 계속 재생됩니다. 끄려면 **완료**를 누르거나 Test E에서 정지하세요.

## 시작 전

1. [ ] 에어팟을 이 아이폰에 연결하고 귀에 착용했다
2. [ ] **맥북 Bluetooth를 껐다** (AirPods가 맥북으로 넘어가면 소리와 센서가 끊깁니다)
3. [ ] 아이폰 **미디어 볼륨**을 중간쯤으로 맞췄다 (앱의 볼륨 슬라이더는 그 위에서 곱해집니다)
4. [ ] 모션 권한 팝업을 허용했다

## 음원 바꾸는 법

- 앱은 `AirPodsProMotion/Audio/bgm.caf` **파일 하나**만 재생합니다. 다른 곡으로 바꾸려면 이 파일만 교체하고 다시 빌드하세요
  (파일 이름 `bgm`, 확장자는 caf / m4a / mp3 / wav / aac 중 아무거나).
- 기본 음원은 직접 합성한 것입니다 (킥 드럼 + 클랩 + 하이햇 + 베이스 + 아르페지오, 48초, 저작권 없음).
  `python3 tools/make_bgm.py` 로 다시 만들 수 있습니다.
- 끊김 없는 반복을 원하면 **caf나 wav 같은 비압축 포맷**을 권합니다 (mp3·m4a는 파일 끝에 미세한 빈 구간이 생길 수 있음).

## A. BGM (Test E)

Test E 화면: **시작 / 정지** 버튼, 재생 경과 시간, 출력 경로, 마지막 인터럽션 시각, 재시작 횟수,
볼륨 슬라이더, **"에어팟이 빠지면: 폰 스피커로 계속"** 스위치, **30분 타이머** 스위치가 있습니다.
시작하면 볼륨이 **0에서 목표값까지 3초 동안** 서서히 올라갑니다. 로그는 앱 Documents의 `bgm_*.csv`에 쌓입니다.

각 상태에서 시작 버튼을 누른 뒤 아래를 확인하세요.

| # | 확인 | 화면 켠 상태 | 홈으로 나간 상태 | 화면 잠금 상태 |
|---|---|---|---|---|
| 1 | BGM이 **에어팟으로** 나온다 (화면의 출력에 에어팟 이름) | | | |
| 1 | **페이드 인**이 자연스럽다 (처음 3초) | | | |
| 2 | **30분 연속** 끊김이 없다 (30분 타이머 스위치를 켜 두면 자동 정지) | | | |
| 2 | 로그의 **재시작 횟수**가 0이다 | | | |
| 3 | **시리를 호출**한 뒤 BGM이 다시 이어진다 | | | |
| 3 | **전화를 받은 뒤** BGM이 다시 이어진다 | | | |

> 30분은 길어서, 처음에는 5분만 해 보고 재시작 횟수와 끊김을 본 뒤 30분을 하셔도 됩니다.
> 홈/잠금 상태 확인은 시작 후 홈으로 나가거나 잠금 버튼을 누르세요. 끝나면 앱을 열어 재시작 횟수를 보세요.

### 4. 에어팟을 귀에서 뺐을 때

BGM이 재생 중일 때 에어팟을 **귀에서 빼거나 케이스에 넣고**, 아래 두 설정을 각각 확인하세요.
(에어팟이 연결 해제되면 출력 경로가 바뀌며 `oldDeviceUnavailable`이 로그에 남습니다.)

| 설정 | 기대 | 실제 (BGM이 어떻게 됐나) | 통과/실패 |
|---|---|---|---|
| (가) 스위치 **끔** = 멈춤 | BGM이 멈춘다 | | |
| (나) 스위치 **켬** = 폰 스피커로 계속 | 폰 스피커로 계속 나온다 | | |

로그 확인: `bgm_*.csv` 에서 `route change reason=oldDeviceUnavailable`, 그 다음 줄의 `action: ...` 문구를 봅니다.

## B. 스트레칭 가이드 화면 (Test F)

Test F 화면: 위쪽에 3D 머리 두 개, 아래쪽에 현재 단계 문구, 진행 바, 목표와의 각도 차이, **좌우 반전** 스위치가 있습니다.

- **불투명 청록 머리** = 내 에어팟 센서값을 그대로 반영
- **반투명 주황 머리** = 목표 자세 (자동으로 움직임)
- 시작을 누르면 **"정면을 보세요" 3초 카운트다운**이 나오고, 그 순간의 yaw를 0으로 맞춥니다 (이후 yaw는 상대값)
- 화면이 켜져 있는 동안 화면이 저절로 꺼지지 않습니다 (화면을 나가면 원래대로 돌아옴)
- 예시 미션: **목 옆으로 기울이기** (오른쪽 3초 유지 → 정면으로 돌아와 가만히 1.5초 → 왼쪽 3초 유지 → 정면으로 돌아와 가만히 1.5초, 총 17초)
- **"정면으로 돌아와 가만히" 구간에서는 화면이 자동으로 정면(0)을 다시 맞춥니다.** (기울인 채로 있으면 보정하지 않음) 그래서 스트레칭 도중 "정면 맞추기"를 누를 필요가 없습니다.
- 센서 원값과 보정값은 앱 Documents의 `stretchguide_*.csv`에 남습니다 (어긋날 때 원인을 보려는 용도).

| # | 확인 | 통과/실패 | 메모 |
|---|---|---|---|
| 1 | 카운트다운 중 정면을 본 뒤, 시작되면 불투명 머리가 정면을 향한다 | | |
| 2 | 불투명 머리가 내 **고개 움직임을 따라** 움직인다 (숙임 / 기울임 / 좌우 돌림 각각) | | |
| 3 | 반투명 목표 머리가 단계 문구대로 움직인다 ("오른쪽으로 기울이기 3초" 등) | | |
| 4 | 단계 문구의 **남은 초**와 **진행 바**가 맞게 움직인다 | | |
| 5 | **각도 차이**(pitch/roll/yaw)가 내가 목표를 따라 하면 작아지고 반대로 하면 커진다 | | |
| 6 | 화면이 미션 중에 저절로 꺼지지 않는다 / 나갔다 들어오면 원래 설정으로 돌아온다 | | |
| 7 | "정면으로 돌아와 가만히" 구간에서 "정면 자동 보정 중"이 뜨고, 그 뒤 기울이기 때도 머리가 한쪽으로 치우치지 않는다 (정면 맞추기 버튼을 안 눌러도 됨) | | |
